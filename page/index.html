USD quote

Each run is a skail function that fetches the price of 1 US dollar every minute and waits, with a durable delay, until you stop it. Stop the app in the middle of a run and start it again: the run goes on from where it was, and its next quotes show up here.

No runs yet. Pick a currency and start a run.

This is a demo, not production code: the rates come from the public Coinbase API, are for display only and are not guaranteed. Each run is also in the skail Monitor.
